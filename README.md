# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 索引色板（V1.1）

在原逐格真彩色预览之上，新增完整的索引色字符图制作能力，可与真彩色模式随时切换：

- **有限色板提取**：基于 OKLab 感知色空间的加权 k-means，权重结合字符墨色覆盖率与
  像素 alpha；空格单元归入背景项，全透明单元生成独立透明项，半透明边缘单独计数。
- **层次保序**：对自动色做明度保序回归，避免颜色接近却使明暗层级倒置；面板以
  Kendall τ 给出可核对的层级一致性指标。
- **锁色与吸色**：可从原图或预览吸取颜色并锁定，也可手动输入或从色板条目直接锁定；
  锁色保存在文档中，更换图片后依然保留，自动色重新提取。
- **锁色冲突**：自动识别重复与近似锁色；锁色超出色数上限时，在「显眼小区域优先」
  与「整体色差优先」两种策略下分别求解并对比平均 ΔE 与舍弃显眼度。
- **点击追踪**：点击预览或色板条目，高亮该色覆盖的全部单元并显示数量。
- **撤销**：加锁、解锁、改色数、切策略、重提取等色板调整均可单步撤销，
  一次撤销同步恢复颜色分配、来源标记、锁色集合与导出索引。
- **索引 PNG 导出**：手写 PNG 编码器输出 color type 3（PLTE + tRNS），
  与预览共用同一色板，含背景项与透明项，绝不回退真彩色；导出前校验所有单元
  均已归并到色板索引。
- **可核对指标**：实际占用色数、平均/最大 ΔE、层级 τ、半透明边缘数、透明单元数、
  每条目的占用与边缘计数均在面板实时显示。

### 目录

- `src/features/palette/lib/color.ts`：OKLab、ΔE、字符覆盖率、层级 τ
- `src/features/palette/lib/quantize.ts`：加权量化、锁色冲突双策略、保序修正
- `src/features/palette/lib/pngIndexed.ts`：索引 PNG（color type 3）编码器
- `src/features/palette/model/usePaletteSession.ts`：锁色、撤销栈、追踪会话
- `src/features/palette/ui/`：色板面板与吸色层
